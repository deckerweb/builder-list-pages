Block-based builders

Tool Supported Note

GenerateBlocks Yes Free / Pro

Spectra Blocks Yes Free / Pro
Spectra Legacy Yes Free / Pro

The corresponding plugin or theme must be available for active filters. WordPress core blocks do not count as another builder. Global headers, footers and automatic templates are not automatically attributed to a page.
